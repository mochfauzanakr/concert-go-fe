# Koreksi scope tampilan

Arahan terbaru pengguna, 5 November 2026: pertahankan tampilan sebelum tahap 4 dan lakukan perapian kecil, bukan penggantian desain menyeluruh.

- Landing, beranda user, katalog, detail acara, dan footer telah dikembalikan ke tampilan sebelumnya.
- Penerapan discovery baru serta route publik `/events` dibatalkan. Route katalog/detail yang berjalan tetap `/user/events` dan `/user/events/[id]`.
- Prototipe `/design/discovery` tetap merupakan bahan studi tahap 3, bukan arah visual yang otomatis disetujui untuk diterapkan.
- Profil demo tetap mengikuti formulir profil nyata, sesuai permintaan pengguna sebelumnya.
- Perbaikan callback, refresh token, dan penghapusan label/fitur member serta poin tetap dalam scope.
- Perapian selanjutnya terbatas pada spacing, alignment, ukuran kontrol, dan masalah responsivitas yang ditemukan; warna utama dan struktur halaman dipertahankan.
- Backend konser/tiket tidak ditambahkan. Flow tiket yang sudah ada tetap simulasi sampai API disediakan pemilik backend.

Koreksi ini mengesampingkan rencana penggantian visual luas pada dokumen tahap 3. Pengguna kemudian mengizinkan kelanjutan perapian commit dan push; izin tersebut tidak mengubah batas tampilan di atas.

Arahan Git terakhir: commit pemilik repository tidak diubah, termasuk SHA. Perbaikan ditambahkan di atas riwayat remote dengan push biasa.
